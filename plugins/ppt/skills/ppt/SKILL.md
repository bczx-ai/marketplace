# PowerPoint 演示文稿

输出必须是可编辑的 `.pptx`，并经过内容和视觉两轮检查。

## 选择工具

- 从零创建：优先 `pptxgenjs`；环境只有 Python 时使用 `python-pptx`。
- 读取内容：使用 `markitdown` 或解包 OOXML。
- 基于模板编辑：保留母版、主题和版式，优先修改现有占位符。
- 渲染验证：使用 LibreOffice 导出 PDF，再用 `pdftoppm` 生成逐页图片。

## 工作流

1. 确认受众、目的、页数、比例、品牌素材和交付语言。
2. 先形成逐页叙事：每页只承担一个结论，标题直接表达结论。
3. 使用真实图表、图片、表格或清晰结构承载信息；不要用装饰元素代替内容。
4. 保持网格、边距、字体、色彩和图形语义一致，正文不小于可读尺寸。
5. 导出后检查文本顺序和缺失内容，再逐页查看渲染图，修复重叠、截断、低对比度和越界。

## 编辑与安全

- 编辑现有文件时输出新文件，不覆盖原件；模板中的未替换占位文本必须清理。
- 图表数据应可追溯，涉及用户数据时不上传到外部服务。
- 合并演示文稿前先确认目标主题和页面比例，避免破坏母版关系。
- 交付 `.pptx`；预览 PDF 和渲染图片仅在用户需要时保留。
