# PDF

根据任务选择成熟工具，不手工解析 PDF 字节结构。

## 选择工具

- 合并、拆分、旋转、元数据和加密：`pypdf`。
- 文本与表格提取：`pdfplumber`，必要时结合 `pdftotext`。
- 创建排版型 PDF：`reportlab`；已有 Office 源文件时优先从源文件导出。
- 页面渲染：Poppler `pdftoppm`。
- 扫描件 OCR：`ocrmypdf` 或 Tesseract，保留原始图像层。
- 表单：优先填写现有 AcroForm 字段；没有字段时再使用坐标叠加。

## 工作流

1. 检查页数、页面尺寸、旋转、加密状态、文本层、表单字段和文件大小。
2. 对输入文件保持只读，写入新的输出路径。
3. 提取内容时区分原生文本与 OCR 结果，并保留页码来源。
4. 创建或修改后重新打开 PDF，验证页数、元数据、表单字段和加密设置。
5. 渲染所有页面或代表性页面，检查空白页、裁切、重叠、乱码、低对比度和错误方向。

## 安全与质量

- 不尝试绕过未知密码；解密只使用用户明确提供且有权使用的密码。
- 涉及签名时不声称修改后的文件仍保留原数字签名有效性。
- OCR、压缩和格式转换可能改变视觉质量，先保留原件并说明影响。
- 最终交付 PDF；临时图片、OCR 中间文件和解包内容仅在用户要求时保留。
