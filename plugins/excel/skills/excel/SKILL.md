# Excel 工作簿

优先使用 Python `openpyxl` 处理格式和公式，使用 `pandas` 处理大批量表格数据。

## 工作流

1. 读取工作簿结构、表名、已用区域、公式、合并单元格、命名区域和现有样式。
2. 编辑现有文件时输出新文件；`.xlsm` 必须使用 `keep_vba=True` 保留宏。
3. 匹配原文件格式约定，只改任务要求的单元格和结构。
4. 需要动态结果时写公式，不硬编码计算值；公式引用要固定正确的相对/绝对地址。
5. 使用 LibreOffice 无界面模式重算含公式文件，再以 `data_only=True` 读取关键结果，检查公式错误和边界值。
6. 抽查表头、筛选、冻结窗格、数字格式、列宽、打印区域和图表数据范围。

## 数据与格式

- 日期、百分比、金额和标识符使用正确的单元格类型与格式；前导零标识符按文本处理。
- 数据清洗保留原始字段或输出映射说明，不静默丢弃无法解析的行。
- 新建供他人填写的模板应标出输入区域，并提供一行真实格式的示例。
- 外部链接、宏、隐藏表和公式属于敏感结构，修改前先确认影响。

## 交付

确保最终文件能重新打开，表名和用户指定列名完全一致，公式无错误。CSV/TSV 任务要确认编码、分隔符和换行格式。
