TENCENT DOCS OPENAPI

在线文档成为可执行信息

连接腾讯文档开放平台，保存应用凭据后自动打开官方扫码登录页，由 Brain 安全保管并刷新授权信息。

OAuth2 扫码登录自动刷新权限变更确认

01 / 功能

覆盖核心工作对象

文档与文件

查询文件列表和元数据，读取或更新在线文档，并处理导入导出工作流。

在线表格

读取工作表与单元格数据，按官方接口批量更新结构化业务信息。

协作权限

查看协作者与权限状态，在确认后添加成员或调整共享范围。

02 / 连接

连接一次，按权限执行

准备应用

在腾讯文档开放平台创建并审核第三方应用，取得 Client ID 与 Client Secret。

登记回调

将当前 Brain Agent 空间的 HTTPS OAuth 回调地址加入应用白名单。

扫码授权

安装后填写应用凭据，Brain 自动打开腾讯文档登录页，扫码确认后即可使用。

03 / 使用场景

可以直接这样说

“列出最近更新的腾讯文档，并按负责人归类。”
“读取项目台账中的本周数据，汇总异常项。”
“检查这份文档的协作者权限，给出最小权限调整方案。”

WORKING BOUNDARY

凭据和协作者权限安全管理

应用凭据由 Brain 保管；文档、表格和共享权限操作遵循腾讯文档授权范围，权限变更前明确确认。
