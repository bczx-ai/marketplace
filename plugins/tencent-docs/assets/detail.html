TENCENT DOCS OPENAPI

在线文档成为可执行信息

连接腾讯文档开放平台，使用受控的 Client ID 与 Access Token 查询和管理在线文档、表格、文件、协作者与权限。

开放平台受控配置权限变更确认

01 / 功能

文档与文件

查询文件列表和元数据，读取或更新在线文档，并处理导入导出工作流。

在线表格

读取工作表与单元格数据，按官方接口批量更新结构化业务信息。

协作权限

查看协作者与权限状态，在确认后添加成员或调整共享范围。

02 / 使用场景

“列出最近更新的腾讯文档，并按负责人归类。”
“读取项目台账中的本周数据，汇总异常项。”
“检查这份文档的协作者权限，给出最小权限调整方案。”
