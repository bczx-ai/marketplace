GITLAB

原生查看 MR 与 Issue，再用 glab 完成研发协作

通过 Brain 原生扩展打开 Merge Request 和 Issue Board，并让 Agent 使用 GitLab 官方 CLI 处理仓库、pipeline、job、Release 与 GitLab API。

原生 MR 与 Issue 面板官方 glab CLI高影响操作确认

01 / 功能

Issue 与 MR

在原生面板查看 MR 和 Issue Board，并由 Agent 搜索事项、审查差异或处理评审。

CI/CD 排障

查看 pipeline、job 和日志，定位失败阶段并整理可执行修复建议。

项目与发布

查询项目、成员和 Release，并通过同源 API 补足专用命令未覆盖的能力。

02 / 使用场景

“审查当前项目待合并的 MR，汇总变更风险和阻塞项。”
“分析最近失败的 pipeline 和 job 日志，定位首个有效错误。”
“根据当前改动创建 Issue 或 MR，提交前先确认标题和描述。”
