GITLAB CLI

一套工作流覆盖公网与私有实例

填写 hostname 后自动打开对应实例的 glab 授权页面，支持 GitLab.com 或企业私有 GitLab 的项目、Issue、MR、CI/CD、Release 与 API。

公网与私有实例自动网页登录高影响操作确认

01 / 功能

Issue 与 MR

搜索事项、查看差异与评审状态，在确认后创建、评论或审批。

CI/CD 排障

查看 pipeline、job 和日志，定位失败阶段并整理可执行修复建议。

项目与发布

查询项目、成员和 Release，并通过同源 API 补足专用命令未覆盖的能力。

02 / 使用场景

“汇总私有 GitLab 项目中待评审的 MR。”
“分析最近失败的 pipeline，定位首个有效错误。”
“为这个缺陷创建 Issue，提交前先确认标题和描述。”
