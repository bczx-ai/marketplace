GITHUB CLI

从代码审查到自动化运行

安装后自动打开 GitHub 官方 gh CLI 授权页面，登录后浏览仓库、管理 Issue 与 Pull Request、诊断 Actions，并在需要时访问 GitHub API。

自动浏览器授权结构化输出写操作先确认

01 / 功能

覆盖核心工作对象

Issue 与 PR

查询事项、检查差异和评审状态，在确认后创建、评论、review 或合并。

Actions 诊断

查看 workflow、run、check 和日志，快速定位失败任务与根因。

仓库与发布

查询仓库、分支和 Release，并用 GraphQL 或 REST API 补充高级操作。

02 / 使用场景

可以直接这样说

“列出待我评审的 PR，并按风险排序。”
“分析最近一次 Actions 失败，给出最小修复。”
“整理里程碑中的开放 Issue，生成发布清单。”

WORKING BOUNDARY

仓库写操作保持可审查

读取操作可直接进行；创建或修改 Issue、Pull Request、Workflow 和 Release 前确认目标仓库与影响范围。
