WEBAPP TESTING

验证本地 Web 应用的真实行为

管理一个或多个开发服务器，通过 Playwright 操作页面、检查渲染后的 DOM、浏览器日志和截图，复现并定位界面问题。

本地服务编排Playwright 自动化截图与控制台检查

01 / 核心能力

从启动服务到验证结果

适合本地功能回归、交互问题复现和跨页面端到端检查。

服务管理

启动一个或多个本地开发服务器，等待就绪后执行测试，并在结束时清理进程。

启动 · 就绪检测 · 清理
页面自动化

基于渲染后的页面定位元素，完成点击、输入、导航和状态断言。

DOM · 交互 · 断言
问题诊断

采集截图和控制台日志，检查实际呈现与错误信息，缩小故障范围。

截图 · 日志 · 复现

02 / 工作方式

运行真实应用，检查真实结果

  1. 01启动环境

    运行开发服务器并确认页面可以访问。

  2. 02执行流程

    按用户路径操作页面并记录关键状态。

  3. 03收集证据

    结合 DOM、截图与日志判断是否通过。

03 / 示例请求

可以直接这样说

“测试这个本地应用的登录和提交流程。”
“复现这个界面问题并检查控制台错误。”
“截取桌面端和移动端页面，确认布局正常。”

WORKING BOUNDARY

只验证真实行为，不伪造通过

运行真实应用并检查交互、日志和截图；服务未启动或环境异常时明确失败，不用静态猜测替代测试。
