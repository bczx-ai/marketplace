钉钉

让消息、文档、日程与业务数据进入同一条 Agent 工作流。

通过官方 dws CLI 和生产推荐的 mono Skill，在账号授权范围内查询、整理与执行钉钉工作。

完整工作台

一套入口，覆盖日常协作与业务操作

沟通

消息、群聊与 DING

搜索会话、管理群成员、发送机器人消息，并订阅个人实时事件。

内容

文档、云盘与知识库

检索和编辑钉钉文档、Markdown、云盘文件与知识库内容。

数据

AI 表格与电子表格

处理记录、字段、视图、图表、仪表盘和电子表格数据。

时间

日程、会议室与待办

查询忙闲、安排会议、预订会议室，并维护个人与团队待办。

组织

通讯录、考勤与审批

查找同事和组织信息，处理考勤、日志、审批与组织业务。

沉淀

听记、邮箱与工作流

读取会议听记、邮件和报告，串联跨产品任务与自动化脚本。

受控执行

先看清目标，再改变工作数据

  1. 发现按需读取当前二进制的 Schema 和帮助，不猜命令或参数。
  2. 确认删除、撤回、拒绝审批等高影响操作先展示摘要并等待确认。
  3. 执行使用结构化 JSON 结果，保留组织、账号与操作上下文。
AUTH BOUNDARY

企业管理员启用 CLI 后授权

安装插件会打开钉钉账号授权页。所有能力遵循当前组织和账号已有权限，凭据不会写入 Skill 或命令参数。
