# Brain Design 信息不全时的处理

默认不问。用户在面板里填过的配置已经是该问的全部。

1. 配置里没写的信息，按最常见的情况假设，直接生成。
2. 把用到的假设列在最后一页的备注里，用户看完再改。
3. 不要写 `.brain/design/question-form.json`，面板已经没有问卷。
4. 不要用纯文字在回复里列问题让用户回答。

只有缺了就没法做的信息才问，例如必须原样保留的数字、必须引用的材料。问的时候：

1. 调用 Brain 自带的 `brain-visualize` 技能，在回复里输出一个 ```visualize 围栏。
2. 围栏里是一张小表单：原生 `radio`、`checkbox`、`text`，最多 3 题，每题有可见的 `label`。
3. 提交按钮的处理器里 `await sendBrainInputBarMessage(content)`，`content` 是一句完整的自然语言，写清问题背景和每个选择的结果，不写内部 id 或序号。
4. 只在用户点击提交时调用，提交期间禁用按钮，失败时在表单里显示原因。
5. 表单发出后停止本轮，等用户发送答案再生成。
