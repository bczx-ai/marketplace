03 / 08

痛点

当前模式的 四种失效方式

🔍

发现路径断头

68% 的安装来自首页栏位前 6 名插件；其余 211 个几乎无人问津

🛡️

没有信任信号

没有评分、没有认证徽章——工单显示用户不敢安装不熟悉的插件代码

📉

创作者毫无激励

今年有 38 位外部贡献者发布了插件；其中只有 4 位发布了第二个

🎫

无人负责的支持负担

本季度有 112 个 GitHub issue 追溯到没有登记维护者的插件

每个痛点都指向同一个根因： 插件没有市场，所以既没有负责人、没有信号，也没有激励.
