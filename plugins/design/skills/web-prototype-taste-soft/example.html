02 · 平台

五个基础原语。不锁定任何智能体框架。自带模型、自带工具、自带沙箱 —— 而运行时、策略与账单都留在一处。

运行时是最无聊的部分。我们偏偏 痴迷 于这份无聊。

01 · 身份

稳定身份，而不是会话 token。

每个智能体都获得一个长期身份：凭据可吊销、策略有作用域，还有一层可随模型更换而存续的可移植记忆。轮换密钥无需重新接入智能体。

// 跨模型更换保持稳定
agent.identity = {
  id: "agent_q7_research",
  policy: "tier-3:read-only",
  memory: halcyon.memory("q7"),
};
