一个安静的地方，写下那些 没人读的文档，并让人真的去读。

Quartz 是为技术写作者准备的工作空间 —— 他们更愿意交付一份干净的更新日志，而不是去赢 Notion 模板大赛。列提纲、起草、评审、发布 —— 全程不用离开键盘。

⌘ K
01 / 提纲 编辑器

一份兼作打字机的提纲。

拖动标题即可重构结构。把某个标题切到专注模式，页面其余部分便淡成一根细线。没有浮动工具栏，没有弹窗宾果 —— 只有你正在输入的那一行。

↳ ⌘ ⇧ O 切换提纲
↳ ⌘ J 专注模式
↳ ⌘ ⏎ 发布草稿
02 / 评审 评审

行内评审，不开 Slack 串

评审人留下的评论串锚定在某一行，解决后即归档 —— 不会在两周后来一句「这是在说啥」而丢掉上下文。

03 / 导出

永远输出 Markdown

导出可以往返：在 Quartz 中打开的文档，写出的 .md 与读入时完全一致。

04 / 历史 审计

Git 级历史记录

每次保存都是一次提交。三次按键即可对比两个版本。

05 / 技术栈 集成

与 Linear、GitHub 及你的 CMS 友好协作

Quartz 会识别你正文里的 Linear 工单 ID，并在侧栏显示其父 issue。把已发布的文档推送到 GitHub 仓库或静态站点 —— 不需要插件市场。

Quartz 不想当 wiki，也不想当 CMS，更不想当第二大脑。
