快速开始

五分钟内同步第一个文件夹。CLI 是最快的路径；桌面应用和 API 客户端封装的都是同一套引擎。

1. 安装 CLI

CLI 以单个二进制文件分发，支持 macOS、Linux 和 Windows。

# macOS · Homebrew
brew install filebase

# Linux · curl
curl -fsSL https://get.filebase.dev | sh

验证安装：

filebase --version
# filebase 0.6.4

2. 认证

使用你的 Filebase 账号登录。token 存储在 ~/.config/filebase/credentials。

filebase auth login
# → opens your browser
# ✓ Logged in as you@example.com
注意
在没有浏览器的服务器上，使用 filebase auth login --device 走设备码流程。

3. 同步文件夹

选择一个本地目录并关联到远程根目录。Filebase 会监听变更，并在后台推送块级差异。

cd ~/projects
filebase init my-team
filebase sync

排除文件

在同步文件夹的根目录添加 .filebaseignore，语法与 .gitignore 相同：

node_modules/
*.log
build/
