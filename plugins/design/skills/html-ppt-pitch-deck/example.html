方案

03

为什么是现在

切入点：agent 已经在桌面上。

零安装阻力

21 个编程 agent 已运行在开发者机器上。Open Design 安装即激活——无需新登录，也没有需要竞争的新席位。

接入，而非重建

Claude Code、Codex 与 Cursor 已经会推理和写代码。我们只围绕它们构建设计原生的运行时。

社区分发

上线以来社区已发布 220+ 个插件——模板、演示文稿、原型。每一个都是免费的获客渠道。

复利式记忆

每个项目都会写入本地设计系统记忆，因此团队待得越久，迁移成本越高。
