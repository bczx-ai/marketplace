GITEE MCP

连接 Gitee 研发协作

通过 Gitee 官方远程 MCP 查询仓库与代码，管理 Issue、Pull Request、Release、评论和通知。

官方远程 MCPPAT 安全连接写操作先确认

01 / 能力

仓库与代码

搜索仓库和代码、读取文件、比较分支或标签。

Issue 与 PR

查看详情和差异，在确认后创建、更新、评论或评审。

Release 与通知

查询发布和个人通知，在确认后创建 Release。

02 / 使用场景

“汇总这个仓库待处理的 Issue 和 PR。”
“比较 release 与 main 分支并说明风险。”
“查看我的 Gitee 通知并按仓库归类。”
