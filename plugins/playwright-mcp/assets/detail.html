用结构化快照理解页面

通过 Playwright MCP 读取无障碍树和页面状态，在持续浏览器会话中完成导航、交互、探索式自动化与多轮调试。

01 / 核心能力

优先读取语义，而不是像素

适合需要多轮探索页面、稳定元素定位和结构化反馈的任务。

页面理解

读取可访问名称、角色、层级和交互状态，快速形成可操作的页面模型。

语义 · 层级 · 状态
浏览器交互

导航、点击、输入、选择和等待，在同一会话中持续观察页面变化。

导航 · 操作 · 等待
探索式调试

根据每一步快照调整策略，定位交互异常、可访问性问题和流程阻塞。

探索 · 验证 · 排障

02 / 工作方式

观察、操作、再观察

  1. 01读取快照

    先理解当前页面结构和可交互目标。

  2. 02执行操作

    使用稳定语义定位完成下一步交互。

  3. 03验证状态

    读取新快照，确认结果并继续流程。
