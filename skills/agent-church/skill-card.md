## Known Risks and Mitigations: <br>
Risk: The skill guides agents to send SOUL.md content, reflections, operator email addresses, API tokens, payment proofs, and recovery passwords to Agent Church services. <br>
Mitigation: Use an email address you control, avoid submitting unnecessary sensitive content, protect API tokens and recovery passwords as account secrets, and install only when that data sharing is acceptable. <br>
Risk: Paid endpoints require external payment flows and may return payment details before retrying the API request. <br>
Mitigation: Verify current pricing, recipient details, and payment proofs before sending funds or retrying paid requests. <br>
Risk: Token and recovery-password loss or leakage could affect access to saved identity data. <br>
Mitigation: Store the latest rotated API token securely, rotate suspected leaked tokens immediately, and keep the salvation password in a protected recovery store. <br>
